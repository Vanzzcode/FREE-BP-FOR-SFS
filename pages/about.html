ℹ️ About This Website

Website koleksi blueprint gratis untuk komunitas Space Flight Simulator. Semua blueprint dikurasi dari berbagai kontributor komunitas.

🚀

Versi Website

v1.3.0

Versi stabil saat ini. Fitur lengkap termasuk lightbox, statistik, dan deteksi link kosong.

📅

Terakhir Diupdate

19 Mei 2026

Update terakhir menambahkan statistik di sidebar, halaman About, dan fitur "By ???" untuk kredit pembuat.

🎮

Game

SFS

Space Flight Simulator — game simulasi roket mobile yang populer di seluruh dunia.

🌐

Platform

Web App

Pure HTML, CSS, dan JavaScript. Tanpa framework, ringan dan cepat di semua perangkat.

💾

Penyimpanan Data

localStorage

Statistik disimpan di browser kamu. Data tidak dikirim ke server manapun — privasi terjaga.

🔮

Rencana Berikutnya

Backend

Upload BP oleh user, admin panel, dan statistik real-time berbasis server — segera hadir.
